# secretProject-QOS
A Restaurant Queue Operation Management System (QOS) is a hardware and software framework designed to manage, streamline, and track customer waitlists from the moment patrons arrive until they are seated. It acts as the operational bridge between waiting guests and floor staff, optimizing table turnover and eliminating physical lobby congestion.
Improved features includes:
+ 2 games
+ points system
+ soup of the day
+ discounts and rewards
